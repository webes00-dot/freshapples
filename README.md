# MNtrees — Minnesota Apple Variety Finder

**Current developer entry point (2026-11-20):**
[Developer handoff: architecture, sources, rules, and remaining gaps](docs/DEVELOPER_HANDOFF_2026-11-20.md).

Read the consolidated [RULEBOOK](docs/RULEBOOK_2026-11-20.md), [operations](docs/OPERATIONS.md), [unified snapshot architecture](docs/UNIFIED_DATA.md), and variety scan policy before changing any import. The Google workbook Rules Master (R01–R32) is the editorial rule register.

- Editorial source: [Consolidated MNtrees Google Sheet](https://docs.google.com/spreadsheets/d/1sTqBuJ2eFHwhLlYHIlXhh6HqgMhcBmVb7o70pvwRtV8/edit), specifically the Brand, Retailer, Variety, Rules, Alias, and Corrections masters.
- Source repository: `webes00-dot/freshapples`, branch `main`.
- Operational flow: scanner observations -> exact-source-ID corrections and catalog normalization -> `dist/data/catalog.json` -> `dist/data/site-data.json` -> UI.
- Machine-readable authority: `config/authority.json`; Python consumers import `scripts/master_config.py`.
- Mandatory build release audit: `scripts/audit_release.py` -> non-public `reports/release_quality.json`.
- Complete developer ZIP: GitHub Actions **Build complete MNtrees developer handoff**, or `python scripts/export_developer_handoff.py` after `bash build.sh`. Include the separate exported native master workbook when sharing with a developer.
- Build and deployment: `bash build.sh`, Cloudflare Pages output `dist`; verify real live deployment separately.
- Reconciliation diagnostic: `reports/entity_reconciliation.json` generated by the site-data build (local non-public report).
- Product observations and historical pricing remain provenance-bearing separate inputs; site-data is the *derived public read model*, not a master.
- Retailer sync is read-only Google Sheets -> GitHub; authenticated scan -> master write-back and brand/retailer dual-role cross-referencing are **not yet automated**.
- Neither scanning nor catalog display establishes verified live inventory.
- The old `README_DEPLOY.md` describes an older 2026-11-17 pilot and is not the current runbook.

```bash
python -m unittest discover -s collector/tests -v
node --check app.js
node --check catalog-model.js
node --check brands.js
node --check retailers.js
bash build.sh
```

For all code and data, clone this private repository or use GitHub **Code -> Download ZIP**; for a bundled build output, tests, reports and checksum manifest, use the **Build complete MNtrees developer handoff** GitHub Actions artifact.
